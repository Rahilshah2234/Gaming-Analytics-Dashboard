# 🎮 Gaming Analytics Dashboard

An interactive Power BI dashboard exploring the relationship between video game sales and esports popularity.

## 📊 Project Overview

This project analyzes video game sales and esports earnings to explore trends in the gaming industry.

### Key Features

* 🎯 **Gaming Sales Analysis** — Explore video game sales data.
* 🏆 **Esports Earnings Analysis** — Examine esports earnings across games.
* 📈 **Top Games** — Compare leading games by sales and esports earnings.
* 🎮 **Genre Analysis** — Explore gaming industry trends by genre.
* 🔍 **Interactive Filtering** — Filter the dashboard to explore specific categories.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* CSV datasets

## 🚀 How to Use

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` file in Power BI Desktop.
4. If prompted, verify the data source paths and refresh the data.
5. Explore the dashboard and its interactive visuals.

## 🎯 Project Objective

To explore gaming industry trends by comparing video game sales with esports earnings and popularity.
